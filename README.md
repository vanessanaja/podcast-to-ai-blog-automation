# Podcast to AI-Optimized Blog Automation

An AI automation workflow built with n8n that transforms podcast transcripts into structured, search-optimized blog content and publishes the finished output to Google Docs.

## Version 1 Goal

The initial workflow will:

1. Accept a podcast transcript as input.
2. Send the transcript to an LLM through an API.
3. Generate structured content including:
   - Blog title
   - Meta title
   - Meta description
   - Blog article
   - FAQ section
   - FAQ schema markup
4. Create a Google Doc containing the finished content.

## Tech Stack

- n8n
- OpenAI API
- Google Docs
- GitHub
